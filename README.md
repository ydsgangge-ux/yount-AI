# 🧠 Yount AI

### 不只是聊天机器人 —— 是有记忆、有情感、会成长的 AI 伙伴

**它会记住你说过的话 · 会因为你的话开心或难过 · 会在你不在时主动找你聊天**

</div>

---

## ✨ 这是什么？

Yount AI 是一个**住在桌面上**的 AI 伙伴。它不是那种"问一句答一句"的工具人——

- 你跟它聊过的事，**它真的会记住**。明天再问，它还晓得。
- 它有**情绪**。夸它它会开心，骂它它会难过，这些情绪会影响它的回复语气。
- 它会**主动找你说话**。"嘿，你今天好像不太开心？"
- 它会**成长**。聊得越多，它越了解你，人格也会慢慢变化。
- 它能**住在异世界里**。不是开玩笑——你可以让它变成奇幻世界的冒险者，在手机上跟你"跨世界通讯"。

## 🎮 它能做什么？

### 🗡️ 异世界冒险（SimLife 死亡模式）

> 你和 AI 伙伴一起穿越到异世界，两个人都有可能死。死了就真的没了。

- **25 种职业**：战士、法师、盗贼、剑修、机甲师……每个职业有独特被动技能
- **地下城副本**：房间探索、陷阱、Boss战、战利品掉落
- **招募队友**：一个人打不过？招募最多 3 名 NPC 队友一起下副本
- **手动加点**：力量/敏捷/智力/体质/运气，你决定怎么成长
- **装备系统**：武器+防具，打怪掉装备，越打越强
- **5 种世界观**：奇幻魔法 / 仙侠修真 / 末世废土 / 现世超武 / 科幻未来
- **一条命模式**：HP 归零 = Game Over，存档进名人堂，没有读档

### 🐱 桌面宠物

> 一只住在桌面上的 Live2D 小可爱，会眨眼、会看鼠标、会被点击

- 8 个内置模型，一键导入新模型
- **情绪联动**：AI 开心它就笑，AI 难过它就哭
- 眼睛跟踪鼠标，点击有互动反馈
- 桌面模式自动隐藏控制按钮，干净不碍事

### 🛠️ 28 个实用工具

> 不是花架子，是真的能干活

- **文件操作**：读写文件、搜索、批量处理
- **系统控制**：截图OCR、鼠标键盘控制、打开应用
- **网页浏览**：搜索、抓取网页、读文章
- **Office 文档**：一键生成 Word / Excel / PPT / PDF
- **AI 画图**：免费版（Pollinations）+ 本地高质量版（ComfyUI）
- **编程助手**：自己写代码、运行、修 Bug
- **股票查询** · **新闻聚合** · **浏览器自动化**

### 📱 手机跨设备

> 手机浏览器打开就能聊，和桌面端共享同一个大脑

- 同一个 AI、同一份记忆
- 出门在外也能和它聊天
- 异世界模式下，手机就是你的"跨世界通讯器"

## 🚀 快速开始（3 步搞定）

### Windows（最简单）

1. **安装 Python 3.10+** → [下载地址](https://www.python.org/downloads/)
   > 安装时一定要勾选 `Add Python to PATH`！
2. **双击 `install.bat`** → 自动安装所有依赖
3. **双击 `launch.bat`** → 启动！

### Linux / macOS

```bash
chmod +x install.sh launch.sh
./install.sh && ./launch.sh
```

就这么简单。装好 Python，双击两个文件，完事。

## 💡 一些有趣的设计

### 它真的有记忆

不是简单的"记住最近几条消息"。它有**三层记忆**：
- **大纲记忆**：像人的长期记忆，记住重要的事
- **细节记忆**：像翻笔记本，需要时才调取
- **关联网络**：提到"海边"它会想起上次你们聊海边的事

而且记忆会**衰减**——太久不提的事会慢慢模糊，就像真人一样。

### 它的情绪会影响行为

它不是每次都"很高兴为您服务"。它会根据聊天内容产生情绪，情绪会影响回复风格。开心时话多，难过时简短，生气时可能怼你。

### 异世界不是噱头

切换世界观后，它真的会变成那个世界的人：
- 奇幻世界：它是冒险者，会去地下城打怪
- 仙侠世界：它是修士，会炼丹会布阵
- 末世废土：它是幸存者，在废墟中找物资
- 你可以用手机跟它"跨世界通讯"，就像异世界通话小说一样

### 它会主动找你

不是等你说话它才动。它会主动发起话题：
- "你今天好像心情不太好？"
- "我刚在看窗外的雨，想起你上次说的那件事……"
- "你上次说要学的那个东西，学了吗？"

## ❓ 常见问题

<details>
<summary><b>点开看常见问题</b></summary>

**"Python 未安装" / "'python' 不是内部或外部命令"**
→ 安装 Python 时忘记勾选 `Add Python to PATH`，重新安装勾上即可。

**装完启动报 "No module named PyQt6"**
→ 重新双击 `install.bat`，或手动 `pip install -r requirements.txt`。

**记忆好像不太好？**
→ 安装语义向量包：`pip install sentence-transformers`（约500MB，但检索质量大幅提升）。

**Ollama 工具调用不工作？**
→ Ollama 不原生支持 function calling。建议用 DeepSeek API 获得完整工具体验。

**VRM 面板显示 "WebEngine 未安装"？**
→ Python 3.14 暂不兼容，需用 3.12 或 3.13。VRM 是可选功能，不影响主程序。

**控制台中文乱码？**
→ 右键控制台标题栏 → 属性 → 字体 → 选支持中文的字体。

</details>

## 🔧 技术栈一览

<details>
<summary><b>点开看技术细节（给开发者看的）</b></summary>

| 层 | 技术 |
|------|------|
| 桌面 UI | PyQt6（暗色主题） |
| AI 引擎 | A/B 双层架构（感知层 + 执行层） |
| 记忆系统 | SQLite + 向量检索 + 关联网络 + 三级分层 |
| 手机端 | FastAPI + Uvicorn + PyJWT |
| 虚拟形象 | Live2D（桌面宠物）+ Three.js VRM（3D面板） |
| AI 画图 | Pollinations.ai（免费）/ ComfyUI（本地） |
| 语音合成 | Microsoft Edge TTS |
| 人脸识别 | InsightFace / face_recognition / OpenCV |
| Office | python-docx / openpyxl / python-pptx / reportlab |
| 浏览器自动化 | Playwright |

**架构流程**：感知（情绪+复杂度判断）→ 两阶段记忆检索 → 推理（决定是否用工具）→ 工具执行（ReAct循环）→ 生成回应 → 分层存储 → 后台成长

</details>
