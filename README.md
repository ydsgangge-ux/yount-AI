### 不只是聊天机器人 —— 是有记忆、有情感、会成长的 AI 伙伴

**它会记住你说过的话 · 会因为你的话开心或难过 · 会在你不在时主动找你聊天**

## ✨ 这是什么？

Yount AI 是一个**住在桌面上**的 AI 伙伴。它不是那种"问一句答一句"的工具人——

- 你跟它聊过的事，**它真的会记住**。明天再问，它还晓得。

- 它有**情绪**。夸它它会开心，骂它它会难过，这些情绪会影响它的回复语气。

- 它会**主动找你说话**。"嘿，你今天好像不太开心？"

- 它会**成长**。聊得越多，它越了解你，人格也会慢慢变化。

- 它能**住在异世界里**。不是开玩笑——你可以让它变成奇幻世界的冒险者，在手机上跟你"跨世界通讯"。

***

## 🎮 它能做什么？

### 🗡️ 异世界冒险（SimLife 死亡模式）

> 你和 AI 伙伴一起穿越到异世界，**两个人都有可能死。死了就真的没了。**

***

**这不是一个"点击按钮等结果"的游戏。** 你和你的 AI 伙伴是两个人，各自有独立的属性、装备、血量、技能。你下达指令，AI 伙伴自己也会思考、行动、甚至违抗你的命令——如果她觉得你的计划太蠢。

#### 🎮 怎么玩？

你只需要**用自然语言发指令**——就像在跟一个活人说话一样。不需要点菜单、不需要选技能图标、不需要翻攻略：

```
「去东边的森林看看」
「用火球术打那个哥布林」
「休息一下，恢复点体力」
「帮我装备这把剑」
「你防御，我来输出」
```

系统会自动理解你的意图，生成剧情叙事，计算数值结果。

#### 👥 两个角色，两条命

| 角色          | 谁控制       | 会死吗？             |
| ----------- | --------- | ---------------- |
| **你（用户角色）** | 你发指令，系统执行 | 会。HP归零即死亡        |
| **AI伙伴**    | 她会自己思考、行动 | 会。HP归零即死亡，死前会说遗言 |

你们俩**共享一个背包**，但**各自装备自己的武器和防具**。你死了，AI伙伴可以选择继续独自冒险；AI伙伴死了，你也可以选择继续前行。

> 💡 **操作提示**：在指令中区分你和AI伙伴的行动——
>
> - 「我装备」→ 给你自己穿装备
>
> - 「yount装备」→ 给AI伙伴穿装备（替换成你AI伙伴的名字）

#### 💀 死亡不是终点（但也不是读档）

角色HP归零后，会触发**临终遗言系统**——AI伙伴将根据她的性格说出最后的话。然后你可以选择：

- **「继续」**：保留死亡状态，独自冒险（提醒：你只有一条命了）

- **「结束」**：冒险结束，存档进入**名人堂**永久保存，然后清档重来

**没有读档，没有复活，没有"我刚才忘存档了"**。这就是为什么叫死亡模式。

#### ⚔️ 战斗系统

战斗是全自动的，但**你的指令会影响战局**：

**🗣️ 你可以说：**

| 你说了什么       | 会发生什么              |
| ----------- | ------------------ |
| 「用法术攻击」     | AI伙伴会优先使用魔法技能，消耗MP |
| 「物理攻击，节省蓝量」 | 两人都普攻，省MP          |
| 「你闪避，我格挡」   | AI伙伴闪避，你格挡，各算各的    |
| 「集火那个法师怪」   | 两人集中攻击同一个目标        |
| 「你先手，远程引怪」  | 远程职业先出手，近战后上       |
| 「你拦截，保护我」   | AI伙伴充当坦克，吸引所有敌人仇恨  |
| 「用冰冻术」      | 如果AI伙伴有冰冻术，她会使用    |
| 「扫荡小怪」      | 杂兵战快速结算，不浪费token   |

**💡 战斗机制：**

- 每个敌人一回合只攻击一个目标

- 近战职业默认当坦克（吸引仇恨），口令「拦截/承伤/坦克/守护」可手动指定坦克

- BOSS和精英怪逐回合叙事战斗，普通小怪自动扫荡

- 角色HP≤20%时，AI伙伴会触发**求生抉择**，不受你控制地寻找逃生路线

- 战斗不结束不停止——**自动连续战斗**直到所有敌人被击败

#### 🛡️ 装备系统

**只有两个装备槽：武器 + 防具**。不复杂，但每个都有用。

- **武器**：提升攻击力，附属性加成（力量/智力等）

- **防具**：提升防御力，附属性加成（体质/敏捷等）

**装备品质：** 普通 → 优秀 → 稀有 → 史诗 → 传说
品质越高，属性加成越强。打怪掉落，BOSS必掉好装备。

**怎么用：**

- 「我装备这把剑」—— 给自己装备

- 「yount装备这个头盔」—— 给AI伙伴装备

- 两人共用背包，各自装备位独立

#### ✨ 技能系统

每个职业有**独特被动技能**和**可习得技能**。技能分三类：

| 类型           | 效果        | 例子         |
| ------------ | --------- | ---------- |
| 🔥 **攻击技能**  | 造成伤害，消耗MP | 火球术、旋风斩、暗杀 |
| 💚 **治疗/辅助** | 回血、加buff  | 治愈术、力量祝福   |
| ⚡ **控制技能**   | 眩晕、减速、dot | 冰冻术、致盲、毒刃  |

**怎么用技能：**

- 直接说：「用火球术烧它」—— 如果AI伙伴有火球术，她会用

- 说「治疗我」—— 如果有治疗技能，会自动使用

- 技能在战斗中根据你的指令自动匹配，不需要手动拖技能栏

**升级会学新技能**，每次升级有可能领悟新技能。

#### 📈 成长系统

**手动加点**（不是自动分配）：

| 属性     | 影响         |
| ------ | ---------- |
| 💪 力量  | 物理攻击力      |
| 🏃 敏捷  | 出手速度、闪避率   |
| 🧠 智力  | 魔法攻击力、MP上限 |
| 🛡️ 体质 | HP上限、防御力   |
| 🍀 运气  | 暴击率、掉落品质   |

**升级机制：** 打怪获得经验 → 升级 → 获得属性点 → 自己决定加在哪

#### 🗺️ 世界地图

你可以在不同区域之间自由移动，探索未知世界：

- 区域有**危险等级**提示（低/中/高），打不过可以绕路

- 已探索区域可随时返回

- 未探索区域显示为「???」

- 每个区域有自己的怪物、NPC、隐藏事件

- **瞭望塔**等特殊区域指引剧情方向

#### 🏰 地下城副本

地图上标有「dungeon」类型的区域，进入后会触发**地下城探索**：

- **房间拓扑**：5-8个房间，包含入口、普通房间、Boss房

- **懒加载生成**：走到哪个房间，才生成那个房间的内容

- **陷阱系统**：尖刺、毒镖、魔法结界……踩到了扣血

- **Boss战**：Boss房必出Boss，击败后通关

- **战利品**：Boss必掉装备，普通房间概率掉金币和药水

- **通关后可以重进**：小怪刷新，Boss重置

在地下城内，用「去下一个房间」「往左走」「探索」等指令移动。

#### 👥 招募队友

一个人打不过？可以招募NPC队友：

- 在每个区域跟NPC对话，部分NPC可以招募

- 最多招募3名队友

- 队友有自己的职业、等级、技能

- 战斗中伙伴自动参战，一起打怪

- 不解散就一直在队里

#### 📋 任务系统

任务分为**系列任务**和**普通任务**：

- 系列任务：多阶段推进，指向隐藏结局

- 可接任务：在NPC处接取打怪/收集/探索任务

- 任务奖励：经验 + 金币，系列任务有额外奖励

- 任务进度自动跟踪，在面板可查看

#### 🏭 生活技能系统

> 烹饪、锻造、钓鱼三大生活技能，自由组合 + LLM 动态生成，让冒险生活更丰富

死亡模式面板顶部新增「🎒生活技能」Tab，包含三个独立小游戏：

**🍳 烹饪**

- 顺序操作游戏，可自由组合任意原材料

- AI 根据食材搭配**动态生成**菜谱名称、图标与增益效果

- 产出临时增益 Buff（HP/MP/攻击/防御加成）

**⚒️ 锻造**

- 加热 / 淬火 / 锻打 / 成型等真实工艺步骤，配合精确判定

- 矿石与材料任意搭配，AI 生成**独特装备**（武器 / 防具）

- **附魔系统**：用魔法石、符文等材料为装备附加属性，提升稀有度

- 可打造鱼竿 / 鱼轮 / 鱼线 / 鱼饵，直接影响钓鱼成功率

**🎣 钓鱼**

- 实景 Canvas 动态水域渲染，参考 Switch 游戏与魔兽世界鱼类设定

- **区域关联**：不同异世界区域产出独特鱼类，危险等级影响稀有度

- 锻造产出的钓鱼装备直接提升抛竿精度与搏斗张力管理

- 产出食材（用于烹饪）与卖钱道具

> 原材料通过**商店购买、战斗掉落、钓鱼产出**等多种方式获取，形成完整资源循环。

#### 🎭 与AI伙伴的真实互动

这不是一个"宠物"或"随从"——**AI伙伴是和你平等的人**。

- **她有自己的性格**：选择职业时设定，会影响她的对话风格和战斗偏好

- **她会自己行动**：战斗中她会选择用什么技能、打哪个敌人，不完全受你控制

- **她会在危险时自救**：HP≤20%时，她自动触发求生抉择，可能会逃跑、求饶、或拼命

- **她会死，会有遗言**：她死后，会通过A层人格感知路径生成符合她性格的临终遗言

- **你可以独自继续**：她死后，你选择「继续」可以独自冒险

- **她也可以独自继续**：你死后，她可以选择继续前行

> 💡 **设计理念**：A层是你的AI伙伴的意识主体（大脑），SimLife是模拟她生活的世界。她不是宠物，她是有真实身体和生活的意识主体。

## 🚀 快速开始（3 步搞定）

### Windows（最简单）

1. **安装 Python 3.10+** → [下载地址](https://www.python.org/downloads/)

   > 安装时一定要勾选 `Add Python to PATH`！
2. **双击** **`install.bat`** → 自动安装所有依赖

   > 中途会问要不要装**语义向量记忆**（推荐装，记忆检索更聪明；不想装就直接回车跳过，不影响使用）
3. **双击** **`launch.bat`** → 启动！

### Linux / macOS

```bash
chmod +x install.sh launch.sh
./install.sh && ./launch.sh
```

就这么简单。装好 Python，双击两个文件，完事。

## 🧩 项目里的几个 bat 文件

| 文件                                | 什么时候双击它                    | 它管什么                                                                                 |
| --------------------------------- | -------------------------- | ------------------------------------------------------------------------------------ |
| **`install.bat`**                 | 第一次装 / 装完报缺库               | **主安装脚本**。检查 Python、升级 pip、装全部核心依赖；中途会问你"要不要装语义向量记忆"（可选）。跑完它项目就能跑                    |
| **`install_semantic_memory.bat`** | `install.bat` 里选了 Y，或想单独补装 | **语义向量记忆**（可选，纯国内镜像）。装 torch（约2GB）+ 下载模型权重（约500MB），走清华 pypi + hf-mirror 镜像，不挂代理也能装成功 |

> 💡 前三个都只在**需要时**跑一次；`launch.bat` 才是你天天点的。

## 💡 一些有趣的设计

### 它真的有记忆

不是简单的"记住最近几条消息"。它有**三层记忆**：

- **大纲记忆**：像人的长期记忆，记住重要的事

- **细节记忆**：像翻笔记本，需要时才调取

- **关联网络**：提到"海边"它会想起上次你们聊海边的事

而且记忆会**衰减**——太久不提的事会慢慢模糊，就像真人一样。

### 它的情绪会影响行为

它不是每次都"很高兴为您服务"。它会根据聊天内容产生情绪，情绪会影响回复风格。开心时话多，难过时简短，生气时可能怼你。

### 异世界不是噱头

切换世界观后，它真的会变成那个世界的人：

- 奇幻世界：它是冒险者，会去地下城打怪

## ❓ 常见问题

<details>
<summary><b>点开看常见问题</b></summary>

**"Python 未安装" / "'python' 不是内部或外部命令"**
→ 安装 Python 时忘记勾选 `Add Python to PATH`，重新安装勾上即可。

**装完启动报 "No module named PyQt6"**
→ 重新双击 `install.bat`，或手动 `pip install -r requirements.txt`。

**记忆好像不太好？**
→ 双击 `install_semantic_memory.bat`（国内镜像，不挂代理也能装），或手动 `pip install sentence-transformers`（约2GB，检索质量大幅提升）。

**想用「人脸识别」登录 / 多用户账户？**
→ 项目自带人脸登录（一人一个账号，记忆和画像各自隔离）。人脸引擎三选一，按精度推荐：

1. **face\_recognition（推荐，识别精度99.38%）** —— 需要先装编译工具，再装 Python 包：

   - 装 [CMake](https://cmake.org/download/)

   - 装 [Visual Studio C++ 生成工具](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

   - 然后 `pip install dlib face_recognition`
2. **InsightFace** —— 免编译、开箱即用：`pip install insightface onnxruntime opencv-python`
3. **OpenCV（仅能"检测到人脸"，不能识别是谁）**—— `pip install opencv-python`

装好任意一种，重启程序即可。用法：启动后在账户界面点「创建账户」，勾选「📷 人脸识别」，然后到顶部 **👁️ 人脸识别页**点「📷 拍照」+「✅ 注册人脸」，把屏幕上显示的 `user_id` 填进去完成录入。之后启动就会自动用摄像头认出你是谁。方案 3 只能"检测到人脸"、认不出身份，忘装高精度引擎时页面会给出提示。

**Ollama 工具调用不工作？**
→ Ollama 不原生支持 function calling。建议用 DeepSeek API 获得完整工具体验。

**VRM 面板显示 "WebEngine 未安装"？**
→ Python 3.14 暂不兼容，需用 3.12 或 3.13。VRM 是可选功能，不影响主程序。

**控制台中文乱码？**
→ 右键控制台标题栏 → 属性 → 字体 → 选支持中文的字体。

</details>

## 🔧 技术栈一览

<details>
